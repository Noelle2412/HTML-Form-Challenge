This is my solution for the HTML Forms Challenge.
I have added very little CSS, mainly to center ensure the forms have a centered alignment, so instead of a separate file I included it in the head of the document. 
The template has a gap between the checkbox answers and the question for that form, my solution does not have that. Apart from that slight formatting issue, I believe my solution looks very similar to the template.
The ids I have given to some of the elements are a bit unwieldy, in the moment I could not think of any better names.
